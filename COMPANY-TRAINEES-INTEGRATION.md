# Company trainee directory

The existing acceptance sequence is preserved: company accepts the application; student confirms the offer; the existing placement workflow saves the confirmed placement. My Trainees reads only confirmed/active/completed placements for both the verified company and assigned company supervisor. Academic-supervisor identity does not determine company membership. No production records or Firebase configuration were changed.

`Services/CompanyTraineesService.cs` extends the existing authorized TaskService and serves `GET TasksApi.ashx?action=trainees`. The response projects only names, student/placement identifiers, internship, dates and task counts for the authorized placements. No browser credentials, raw user profiles or another company's placements are returned. Statistics count placements, current/completed training and assigned tasks. Task completion does not fabricate approved training hours.

`Company/MyTrainees.aspx` and `Js_project/Company/my-trainees.js` replace demo bindings with this API, dynamic statistics/search/internship/status filters, pagination and a details popup. The page polls every five seconds while visible, prevents overlapping requests, refreshes on focus, and displays unavailable statistics on failure. Storage is not involved. Hours approval is not implemented on this page; the old demo-only controls are hidden rather than pretending to save hours.

`Services/TaskService.cs` additionally verifies company ID when returning eligible placement/student options. `Js_project/Company/ManageTasks.js` refreshes on opening Create Task and polls every five seconds, preserving the selected placement when still authorized. `Company/ManageTasks.aspx` uses an updated script version. The project file includes the new partial service.

Verification: solution/test build succeeded; 213 isolated regression tests passed, including cross-company exclusion with the same supervisor ID, exclusion of unconfirmed placements, correct counts and student-role denial. Web Forms precompilation succeeded with existing Profile-hides-inherited-member warnings in unrelated pages. The dedicated CompanyTrainees.browser.cjs test passed search, counters, details, automatic new-placement update and mobile rendering with all external traffic blocked. No live acceptance or confirmation was submitted during testing. Existing production data was not seeded or altered. These tests do not prove a live end-to-end acceptance transaction.

Manual verification: company accepts an existing student's application, then student confirms it. Open My Trainees as the receiving company; the confirmed placement appears within the five-second refresh interval. Open Create Task and check the same student's name/placement. Another company must not receive that student solely because both students share an academic supervisor. Create an explicitly intended task normally and observe the assigned-task statistic update from Firebase. Browser refresh is also supported; literal zero network latency is not promised.
